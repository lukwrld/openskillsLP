# 100 Open Launchpad

Construa a landing page estática, responsiva e em português da Série de Competências Empreendedoras para a 100 Open Startups seguindo integralmente o briefing anexado. É um projeto novo: implemente toda a página, o toggle claro/escuro/automático e o arquivo de dados isolado da programação com as 16 competências. Não use backend nem formulários reais.

This project was built with [Lovable](https://lovable.dev).
